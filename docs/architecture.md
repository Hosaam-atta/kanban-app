# Architecture

The project is organized by app shell, pages, feature modules, shared UI, global store, and styling.

- `src/app` contains application wiring, providers, and routing.
- `src/pages` contains route-level screens.
- `src/features` groups Kanban domain features.
- `src/shared` contains reusable UI, hooks, constants, utilities, and types.
- `src/store` contains cross-feature state entry points.
